# NoNlab - 三角面数处理模块 (Mesh Optimizer)

一个为 VRChat 改模与 Unity 开发者设计的**极致轻量化、纯 C#、非破坏性**减面工具。无需导出 FBX，无需打开 Blender，在 Unity 编辑器内直接完成 QEM 网格简化。

- 版本：V1.0
- By Ninster-NoNlab
- 纯原生 C#，无第三方依赖，体积极小，非破坏性替换，支持顶点刷选保护

---

## 功能特性 (Features)

- **纯 C# 的 QEM 核心**：二次误差度量算法从零手搓，不依赖任何外部库或 DLL。
- **非破坏性替换**：不生成新 Mesh，而是直接替换 `SkinnedMeshRenderer.sharedMesh` 引用，说人话就是只动层级不动源文件/资产，原 Mesh 数据完全不动。BlendShape、bindpose、动画曲线全部保留，非破坏性，所以应用后支持 `Ctrl+Z` 一键撤销。
- **鼠标拖动组 + 顶点刷选**：
  - 左键单点：采集单个顶点。
  - 鼠标拖动：框选批量采集。
  - `Ctrl` + 左键拖动：框选批量采集（加选）。
  - `Alt` + 左键拖动：框选批量取消采集（减选）。
- **跳数保护扩散**：刷选后自动向外扩散 0-9 层邻居，防止保护边界处的拓扑崩塌。
- **区域分级**：可为每个顶点设置 0 / 1 / 2 三级保护强度。
  - 0 = 可猛砍（代价低）
  - 1 = 正常
  - 2 = 禁止
  - 边界保护优先于本设置。
- **智能边界分类**：自动识别 UV 接缝、硬边、骨骼冲突、开放边，并对这些边禁止折叠。
- **细长结构惩罚**：对飘带、发丝等细长结构增加折叠代价，防止被优先减掉。

### 下载
点击下方链接下载最新版：

- **GitHub 开源地址**：[https://github.com/Ninsterrrr/NoNlab](https://github.com/Ninsterrrr/NoNlab)

### 安装
1. 在 Unity 中打开你的项目。
2. 点击 `Assets` -> `Import Package` -> `Custom Package...`。
3. 选择刚刚下载的 `.unitypackage` 文件。
4. 导入完成后，在顶部菜单栏找到 `NoNlab` -> `三角面数处理模块` 打开窗口。

（或者：直接将下载的 `.unitypackage` 拖入 Unity 的 Project 窗口即可）

## 使用方法 (Usage)

0. 提示：本插件自带扫描UV岛和网格数据打印的调试功能，位于 顶部菜单 `NoNlab` -> `MeshOptimizer`-> `调试`

1. 打开工具：点击 Unity 顶部菜单 `NoNlab` -> `三角面数处理模块`。
2. 选择目标：在窗口顶部，将目标模型的 `SkinnedMeshRenderer` 拖入框内，或者选中模型后点击“从选中获取”。
3. （可选）区域分级：在下拉框中选择顶点的保护强度（0 = 可猛砍，1 = 正常，2 = 禁止）。
4. （可选）刷选保护：
   - 点击“进入刷选模式”。
   - 在 Scene 视图中操作鼠标：
     - 左键单点：采集单个顶点。
     - 鼠标拖动：框选批量采集。
     - `Ctrl` + 左键拖动：框选批量加选。
     - `Alt` + 左键拖动：框选批量减选。
   - 点击“结束并保存选区”，选区会出现在下方的保护列表中。
5. 调整参数：
   - 选择“目标面数比例”（比如 0.5 表示减到一半）。
   - 根据需要调整“跳数”、“UV 绝对接缝阈值”、“细长惩罚倍率”等参数。
6. 预览：点击“预览”，在 Scene 视图中查看减面效果。
7. 应用：确认效果满意后，点击“应用”。原 Mesh 会被替换，`Ctrl+Z` 可以撤回。
8. 取消预览：如果预览效果不满意，点击“取消预览”，模型会恢复原状。

> **参数调整提示**：
> 0 = 可猛砍（代价低），1 = 正常，2 = 禁止。边界保护优先于本设置。

## 参数说明 (Parameters)

| 参数 | 说明 |
| --- | --- |
| 位置容差 | 判定两个顶点是否重合的空间距离阈值 |
| UV 容差 | 判定两个顶点 UV 是否一致的阈值 |
| 硬边夹角阈值 | 超过此角度的边视为硬边，禁止折叠 |
| UV 绝对接缝阈值 | UV 差异超过此值直接判定为接缝，禁止折叠 |
| UV 拉伸倍数 | UV 拉伸严重区域的折叠代价倍率 |
| 骨骼权重阈值 | 主骨骼不同的边禁止折叠 |
| 细长惩罚倍率 | 细长结构区域的折叠代价倍率 |
| 细长长宽比阈值 | 判定三角形是否为细长结构的长宽比阈值 |
| 目标面数比例 | 期望减到的面数比例（0.5 = 减到一半） |
| 使用最优位置 | 是否在折叠时计算二次误差最小的最优位置 |

## 调试 (Debug)

在 Unity 顶部菜单栏找到 `NoNlab` -> `MeshOptimizer` -> `调试`，提供两个排查工具：

- **打印选中模型的网格数据**：在 Console 里输出当前选中模型的顶点数、三角面数、UV 通道、骨骼数、材质球数量、BlendShape 数量等基础信息。
- **扫描多个容差下的 UV 岛**：在多个容差阈值下扫描模型的 UV 岛，输出 UV 岛数量和接缝边数量。调参前跑一遍，可以帮你确定 `UV 绝对接缝阈值` 应该设多少。

## 已知问题 (Known Issues)

- **保护边界处可能存在极小的边缘破损**：在保护区域和非保护区域交界的一圈，可能出现非常轻微的甚至偏大（取决于需要处理的Mesh等因素）网格毛刺。这是 QEM 算法本身的性质，不影响减面效果的主体。建议使用时善用各参数调整和预览功能以及CTRL+Z
- **仅测试于 Unity 2022.3 LTS**：其他版本（2020.3 及以上）理论上兼容，但未逐一验证。
